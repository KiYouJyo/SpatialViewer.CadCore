# SpatialViewer.CadCore v0.12.11

## 中文

v0.12.11 修复了上一轮实机诊断暴露出的真正 reader gate：CadCore 虽然已经具备 Proxy Graphics 映射与 raw command 诊断，但实际 DWG reader 仍继承 ACadSharp 3.7.1 的默认值 `IgnoreProxyGraphics = true`，因此湘源对象的代理图形根本没有进入映射器。

### 修复

- CadCore DWG reader 现在显式设置 `IgnoreProxyGraphics = false`。
- 继续保持 `KeepUnknownEntities = true`。
- `ProxySubentMarker` 作为结构/选择 provenance 保留，不再被计为不支持的显示命令。

### 本次湘源证据

SpatialViewer v0.4.2 的兼容性报告已经确认：

- `LZX_LAND / AcdbLzxLand`：115 个；
- raw proxy command：460 个，全部 framing 正常；
- unknown command：0；
- 每个地块的 command family 都是：
  - 14 = SubentColor；
  - 19 = SubentMarker；
  - 20 = SubentFillon；
  - 33 = LwPolyine。

因此 type 33 不是未知 proprietary opcode，而是 ACadSharp 已知的 lightweight-polyline proxy command。v0.12.11 的目标是先让这些真实 proxy primitive 进入 mapper，再由下一份实机报告准确判断 type 33 是否被正常翻译，或是否因 width / normal / thickness 等安全门禁被保留为 unsupported。

### 不做错误猜测

Autodesk ObjectARX 明确规定 polyline primitive 即使闭合也不可填充。因此本版不会因为 command 20 紧邻 command 33 就把闭合 LwPolyline 强制当成 Polygon 填色，避免制造错误地块几何。

### 兼容性

- Product/File/Informational version: `0.12.11`
- CLR ABI: `1.0.0.0`
- Host Contract: `SpatialViewer.CadHost >=1.0.0,<2.0.0`
- Release manifest schema: `2`

## English

v0.12.11 fixes the real reader gate exposed by the SpatialViewer v0.4.2 field report. CadCore already had proxy-graphics mapping and raw-command diagnostics, but the real DWG reader still inherited ACadSharp 3.7.1's default `IgnoreProxyGraphics = true`, so Xiangyuan proxy primitives never reached the mapper.

The release explicitly enables proxy graphics, preserves SubentMarker provenance, and keeps the existing conservative mapping rules. The observed `LZX_LAND` stream is the known sequence Color(14) / Marker(19) / FillOn(20) / LwPolyine(33), with no unknown opcodes.

v0.12.11 deliberately does not force-fill closed polylines: Autodesk ObjectARX defines polyline primitives as non-fillable even when geometrically closed. The next field report can now reveal whether the parsed type-33 primitives translate normally or are withheld because of width/normal/thickness evidence.

ABI, Host Contract and release manifest schema are unchanged.

## 日本語

v0.12.11 は SpatialViewer v0.4.2 の実機レポートで判明した reader gate を修正します。CadCore には Proxy Graphics mapper と raw-command 診断が既に存在しましたが、実際の DWG reader は ACadSharp 3.7.1 の既定値 `IgnoreProxyGraphics = true` を継承していたため、湘源の proxy primitive が mapper に到達していませんでした。

本版では proxy graphics を明示的に有効化し、SubentMarker を provenance として保持します。観測された `LZX_LAND` は Color(14) / Marker(19) / FillOn(20) / LwPolyine(33) の既知 command sequence で、unknown opcode はありません。

ObjectARX 仕様上 polyline primitive は閉じていても fill 対象ではないため、本版では推測で polygon fill に変換しません。次回の実機レポートで type 33 が正常に translation されたか、width / normal / thickness の安全条件で保留されたかを直接確認できます。

ABI、Host Contract、release manifest schema は変更ありません。
