# SpatialViewer.CadCore v0.9.0

## 中文

v0.9.0 将 CadCore 的更新兼容性从 SpatialViewer 产品版本中彻底解耦。

- Release manifest 升级到 schema 2。
- 删除 `SpatialViewer 0.x.x` 形式的产品版本兼容声明。
- 新增独立 Host Contract：`SpatialViewer.CadHost`。
- 当前内核要求 Host Contract `>= 1.0.0` 且 `< 2.0.0`。
- CLR ABI 继续保持 `1.0.0.0`，程序集绑定兼容性与宿主能力兼容性分别校验。
- `cadcore-release.json` 同时作为独立 GitHub Release asset 发布，使宿主可以在下载完整内核 ZIP 之前完成轻量兼容性预检。
- SHA256SUMS 同时覆盖内核 ZIP 与独立 manifest。

本版本不把 SpatialViewer 的应用版本号作为内核更新资格条件。未来只要 ABI 与 Host Contract 均兼容，较早或较新的 SpatialViewer 产品版本都可以继续使用该内核系列。

## English

v0.9.0 fully decouples CadCore update compatibility from the SpatialViewer product version.

- Upgrades the release manifest to schema 2.
- Removes product-version compatibility strings such as `SpatialViewer 0.x.x`.
- Introduces the independent `SpatialViewer.CadHost` host contract.
- This kernel requires host contract versions `>= 1.0.0` and `< 2.0.0`.
- The CLR ABI remains `1.0.0.0`; assembly binding compatibility and host capability compatibility are validated independently.
- Publishes `cadcore-release.json` as a standalone GitHub Release asset so hosts can perform lightweight compatibility preflight before downloading the full kernel archive.
- SHA256SUMS covers both the kernel ZIP and standalone manifest.

SpatialViewer application product versions are no longer used as an eligibility gate for kernel updates. Future host releases can continue consuming this kernel line whenever both the ABI and host contract remain compatible.

## 日本語

v0.9.0 では、CadCore の更新互換性を SpatialViewer 本体の製品バージョンから完全に分離します。

- Release manifest を schema 2 に更新しました。
- `SpatialViewer 0.x.x` のような製品バージョン互換文字列を廃止しました。
- 独立した Host Contract `SpatialViewer.CadHost` を導入しました。
- 現在のカーネルは Host Contract `>= 1.0.0` かつ `< 2.0.0` を要求します。
- CLR ABI は引き続き `1.0.0.0` で、アセンブリのバインド互換性とホスト機能互換性を個別に検証します。
- 完全なカーネル ZIP を取得する前に軽量な互換性事前確認を行えるよう、`cadcore-release.json` を独立した GitHub Release asset として公開します。
- SHA256SUMS は ZIP と独立 manifest の両方を対象にします。

今後は SpatialViewer 本体の製品バージョンをカーネル更新可否の条件に使用しません。ABI と Host Contract が互換である限り、このカーネル系列を継続して利用できます。
