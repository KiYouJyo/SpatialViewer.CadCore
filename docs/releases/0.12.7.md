# SpatialViewer.CadCore v0.12.7

## 中文

v0.12.7 是面向 **湘源控规实图验收** 的兼容性发布。它把此前已经完成并通过 CI 的湘源研究链完整发布到 CadCore，但仍严格区分“可重复结构证据”和“已命名原生语义”。

### 主要变化

- **湘源对象发现与候选锁定**：支持 conservative vendor classification、known-Xiangyuan discovery、native→普通 CAD conversion diff，以及至少两组独立 conversion pair 的 repeated Unknown candidate consensus。
- **地块属性单变量实验目录**：固定 Parcel Number、Land-use Code/Nature、FAR、建筑密度、绿地率、限高等实验意图，范围指标分别拆成 MIN/MAX，防止不同属性的观测被混入同一 consensus。
- **四类隐私安全证据通道**：
  - raw DXF slot / bounded DWG changed range；
  - Proxy Graphics geometry slot；
  - anonymous object-reference slot；
  - reference endpoint coarse entity kind / custom CLASSES identity。
- **完整图纸 A/B**：两份同源 DWG/DXF 可直接做整图比较。实体只允许通过相同且唯一的 retained handle + exact class identity 配对，不使用坐标、图层、文字或几何近邻猜测。
- **本地 CLI**：新增 explicit Xiangyuan whole-document pair 与 repeated-Unknown candidate pair 两种模式。Unknown candidate 必须来自经过验证的 conversion-consensus JSON，不能手输猜测 proprietary class name。
- **严格 fail-closed**：class/schema/layout/reference 不一致、proxy layout 改变、引用端点结构冲突等情况均停止推断，不制造“看起来合理”的语义。

### 隐私边界

可共享报告只包含 class identity、结构 fingerprint、匿名 DXF group slot、DWG changed range、proxy primitive path/field、reference group code/occurrence 以及聚合计数。

以下内容不进入报告：图纸路径/文件名、entity/target handle、坐标、地块编号、用地性质、指标值、文字内容、raw DWG bytes。

### 实机验收重点

建议在 SpatialViewer 中重点验证：

1. 湘源原生 DWG/DXF 能否稳定打开，未知对象是否仍被保留；
2. Proxy Graphics 的地块边界、标注及辅助线是否能正常 fallback 显示；
3. 修改单个地块属性或边界后的 A/B 是否只产生对应的匿名结构变化；
4. 对象转块/全部炸开后的 conversion diff 是否能稳定锁定消失的 custom class/profile；
5. repeated candidate 是否保持全局 `Unknown`，没有误分类或误语义。

### 发布契约

- Product/File/Informational version: `0.12.7`
- CLR ABI: `1.0.0.0`
- Host Contract: `SpatialViewer.CadHost >=1.0.0,<2.0.0`
- Release manifest schema: `2`

## English

v0.12.7 is an **on-device Xiangyuan Control Planning compatibility acceptance release**. It ships the complete evidence-driven Xiangyuan research pipeline while keeping repeatable structural evidence strictly separate from named native semantics.

Highlights include conservative discovery and conversion consensus, canonical parcel single-variable experiment intents, privacy-safe DXF/DWG/geometry/reference/endpoint evidence, exact-handle whole-document A/B matching, and local CLI modes for explicit Xiangyuan identities or validated repeated-Unknown candidates.

This release does **not** claim complete native Xiangyuan parcel semantics. Unknown candidates remain Unknown, unsupported evidence fails closed, and v0.13.0 remains gated on real Xiangyuan sample evidence plus Reader/display regression.

Compatibility remains CLR ABI `1.0.0.0`, `SpatialViewer.CadHost >=1.0.0,<2.0.0`, manifest schema `2`.

## 日本語

v0.12.7 は **湘源控規の実機互換性検証用リリース**です。保守的な object discovery、native→converted diff、multi-pair candidate consensus、parcel single-variable experiment、DXF/DWG・proxy geometry・reference・endpoint evidence、whole-document A/B matching、local CLI を正式に含みます。

Unknown candidate は引き続き global classifier 上で `Unknown` のままであり、実サンプルの独立検証なしに proprietary class name や parcel semantic を推測しません。構造不一致や unsupported evidence は fail closed です。

本版は native Xiangyuan parcel semantics の完成を宣言しません。v0.13.0 は実湘源サンプルによる Reader/display regression 後にのみ進めます。

互換契約は CLR ABI `1.0.0.0`、`SpatialViewer.CadHost >=1.0.0,<2.0.0`、manifest schema `2` のままです。
