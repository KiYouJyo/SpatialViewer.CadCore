# SpatialViewer.CadCore v0.12.6

## 中文

v0.12.6 继续针对真实 DWG/T20 图纸中仍缺失的轴网/尺寸短线、建筑 tick 与颜色继承问题推进。它包含未单独发布的 v0.12.5 proxy layer provenance 工作，并首次把此前完全丢弃的 ObjectARX Proxy Mesh / Shell 边线纳入安全的 2D fallback。

### 主要变化

- **Proxy Mesh / Shell 边线恢复**：支持有限、共面的 `ProxyMesh` 与 `ProxyShell`，将其边界线恢复为 reader-independent 2D edge set。该路径主要针对自定义尺寸、轴网、建筑 tick 等可能由 mesh/shell edge data 输出的短线。
- **严格拓扑与共面校验**：顶点非有限、非共面、索引越界、零长度边、edge trait 数量不匹配或未知 visibility 值时直接 fail closed，不产生“看起来合理但位置错误”的替代几何。
- **Mesh 顺序按 ObjectARX 语义恢复**：edge data 严格按“所有 row edges → 所有 column edges”的顺序对应。
- **Shell 顺序保留**：按 face-list traversal 恢复边线，不擅自去重共享边，从而保持 edge trait 与 serialized edge slot 的对应关系。
- **逐边显示证据**：保留 ACI color index、raw layer/linetype reference、marker、visibility。仅对有充分定义的 ACI 1–255 直接应用颜色；layer/linetype reference 继续作为 unresolved provenance，不猜测 LayerTableRecord。
- **可见性**：`kAcGiInvisible` edge 不进入正常显示；`kAcGiVisible` 与 `kAcGiSilhouette` 在普通 2D viewer 中保留。
- **transform / clip**：mesh/shell edge set 可正确通过已有 model-transform 与 proxy clip scope。
- **v0.12.5 provenance 合入**：`SUBENT_LAYER` 状态在经过严格 source↔mapped reconciliation 后继续附着到 proxy primitive，并且与 ByLayer/ByBlock color reset 独立。

### 安全边界

- 不使用“长度超过阈值就隐藏”的启发式规则。
- 不把 proxy layer reference 或 `SUBENT_LAYER` 整数直接当作 drawing layer table 下标。
- 不填充 mesh/shell face；v0.12.6 只恢复可信的 2D edge linework。
- 不宣称天正 `TCH_DIMENSION/TCH_DIMENSION2` native semantics 已完成。

### 实图验收

本版本对“缺失的建筑斜 tick/短线”新增了命中真实 proxy primitive 类型的直接修复路径，但仍需要原问题 DWG 再次验证。如果 `2250` 的颜色仍不一致，下一阶段将继续解析 proxy object-reference → layer/linetype 的可信关系，而不是回退到猜测 DIMSTYLE。

### 发布契约

- Product/File/Informational version: `0.12.6`
- CLR ABI: `1.0.0.0`
- Host Contract: `SpatialViewer.CadHost >=1.0.0,<2.0.0`
- Release manifest schema: `2`

## English

v0.12.6 continues the real-DWG/T20 fidelity work for missing axis/dimension strokes, architectural ticks and proxy color inheritance. It includes the unreleased v0.12.5 proxy-layer provenance work and adds a safe 2D fallback for ObjectARX Proxy Mesh/Shell edges that CadCore previously discarded entirely.

### Highlights

- Maps finite coplanar `ProxyMesh` / `ProxyShell` edge linework into reader-independent proxy edge sets.
- Fails closed for non-finite/non-planar geometry, invalid topology, zero-length edges, trait-count mismatches and unknown visibility values.
- Preserves the documented mesh edge-data ordering: all row edges first, then all column edges.
- Preserves shell face-list traversal order rather than deduplicating shared boundaries.
- Retains per-edge ACI color, raw layer/linetype reference, marker and visibility evidence.
- Applies only proven ACI 1–255 color indices; layer/linetype references remain unresolved provenance until a trustworthy object-reference mapping exists.
- Omits invisible edges and retains visible/silhouette edges for ordinary 2D display.
- Keeps edge sets correct through model transforms and proxy clip scopes.
- Includes strict v0.12.5 `SUBENT_LAYER` provenance reconciliation without guessing a drawing-layer index.

This release does not claim complete native Tianzheng dimension semantics. The new path directly targets missing short tick/edge geometry; remaining color inheritance issues will continue from proxy-reference evidence.

## 日本語

v0.12.6 は、実 DWG/T20 で残っている軸・寸法短線、建築 tick、proxy 色継承の問題を継続して修正します。単独リリースしなかった v0.12.5 の proxy layer provenance を含み、従来破棄されていた ObjectARX Proxy Mesh / Shell の edge linework を安全な 2D fallback として追加します。

### 主な変更

- 有限かつ共面な `ProxyMesh` / `ProxyShell` の edge を reader-independent 2D edge set に変換。
- 非有限・非共面、無効 index、zero-length edge、trait count mismatch、未知 visibility は fail closed。
- Mesh edge data は ObjectARX の定義どおり row edge 全体 → column edge 全体の順序を保持。
- Shell は face-list traversal 順序を保持し、共有 edge を推測で dedupe しません。
- edge ごとの ACI color、raw layer/linetype reference、marker、visibility を保持。
- ACI 1–255 のみ直接色として適用し、layer/linetype reference は解決根拠が得られるまで provenance のまま保持。
- invisible edge は描画せず、visible / silhouette edge は通常の 2D 表示で保持。
- model transform / proxy clip scope を通過しても edge set を維持。
- v0.12.5 の `SUBENT_LAYER` provenance reconciliation も含みます。

本版は天正 dimension native semantics の完成を宣言しません。欠落していた短い tick/edge geometry を直接対象にし、色継承の残課題は proxy reference の証拠から継続します。
