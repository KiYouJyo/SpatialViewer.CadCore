# SpatialViewer.CadCore v0.12.14

## 中文

v0.12.14 修复 v0.12.13 已生成地块代码但仍可能被后续不透明用地色块完全覆盖的问题。

### 根因收敛

你导出的 v0.12.13 兼容性报告已经确认：

- 实机确实运行 `CadCore 0.12.13.0`；
- 115 个 `LZX_LAND / AcdbLzxLand` 全部保持 `ProxyGraphics`；
- translated = 115；
- unsupported = 0。

因此代码生成和 0.12.12 色块共享的对象识别/边界条件不是主要故障点。v0.12.13 唯一新的显示链是把代码挂到真实 `YD-CODE` Scene 图层，而 Scene 又按源图层顺序绘制；后绘制的不透明地块填充可以把文字完全盖住。

### 修复

- `YD-CODE` 在 Scene 中固定最后绘制；
- UI 左侧图层列表仍使用现有独立字母排序，不受影响；
- 关闭 `YD-CODE` 仍会隐藏代码；
- 代码颜色仍使用 `YD-CODE` 的真实 CAD 颜色；
- 自适应字号由 `min(width,height) × 0.12` 调整为 `× 0.18`；
- 最大字号由 4 提高到 8 个图纸单位；
- 新增 overlay metadata 便于后续继续定位。

### 不变

0.12.12 已正确工作的用地色块、地块边界、弧线、普通 CAD 文字/属性、天正和 ABI 均不改变。

- Product/File/Informational version: `0.12.14`
- CLR ABI: `1.0.0.0`

---

## English

v0.12.14 fixes the downstream display failure where generated Xiangyuan parcel-code labels could be completely covered by opaque parcel fills rendered from later CAD scene layers.

The v0.12.13 field report confirms all 115 LZX_LAND proxy entities translate with zero unsupported commands, narrowing the failure to the label display path. YD-CODE is now rendered last while retaining its real visibility and CAD color. Generated label height is also increased conservatively for whole-plan legibility.

UI layer sorting, generic CAD text, parcel fill behavior and ABI remain unchanged.
