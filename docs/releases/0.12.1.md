# SpatialViewer.CadCore v0.12.1

## 中文

v0.12.1 是基于真实建筑 DWG/T20 对照结果完成的 **二维显示保真修复版本**。本版本不扩大天正 proprietary native-semantic 声明，而是优先修复 v0.12.0 实图中暴露出的图框、轴号、门窗、旋转对象、Proxy Graphics 与颜色/线宽显示差异。

### Proxy Graphics 与构件显示

- 新增 `ProxyText` / `ProxyUnicodeText` 显示 fallback，轴号及第三方自定义注释文字可以进入 reader-independent Scene。
- 新增安全的 `ProxyLwPolyline`，保留 closed state 与 bulge；弧段继续使用解析型 `ArcGeometry`，不退化为直线弦。
- 新增平衡的二维 model-transform stack，支持平移、旋转、等比缩放；非均匀缩放、反射、非平面/畸形矩阵与不平衡 stack 继续 fail closed。
- 新增三点圆与三点 simple arc fallback；圆弧 sweep 由 Autodesk 定义的 start / point-on-arc / end 顺序确定。ArcSector / ArcChord 不被伪装成普通圆弧。
- 新增精确二维 Proxy Clip：支持矩形、多边形、嵌套 clip，以及随 model transform 旋转的裁剪边界。裁剪贯通 Scene bounds、hit testing、RenderPreparation 与 Win2D/Direct2D，不用 axis-aligned bbox 冒充旋转 polygon。

### 颜色与线宽

- Proxy subentity 现在可应用显式 ACI、显式 TrueColor RGB / ACI 与标准 lineweight。
- `ByLayer` / `ByBlock` / default lineweight 会安全回退到包含该 Proxy 的 custom entity 表现，不保留前一个 subentity 的陈旧 override。
- `Foreground` / `None`、`ByDIPs`、非法值等没有足够确定语义的状态不会被猜测；它们会清除不安全 override 并保持 fail-safe fallback。
- Proxy layer-index / linetype-index 暂不猜测为文档 table entry；本版本不宣称完整 subentity layer/linetype traits。

### 图框、块、Layout 与外部参照

- 修复匿名/动态 block 被 `name.StartsWith('*')` 过度过滤的问题：`*U###`、TABLE cache 等实际绘图 block 不再被误删，只排除内部 Model/Paper Space records。
- 修复 ACadSharp angle boundary：Reader 已把 `IsAngle` DXF 值转换为 radians，CadCore 不再二次执行 degree→radian。ARC、TEXT/MTEXT、ATTRIB、INSERT、HATCH 与 viewport twist 的旋转恢复正确。
- 修复普通文字、dimension text 与 ellipse 的绕点旋转顺序，旋转不再错误地绕世界原点漂移。
- 新增 privacy-safe source profiler，区分 Paper Space、viewport、匿名/动态 block、TABLE cache 与 Xref dependency，只输出结构计数，不输出图纸文字、handle 或 Xref path。
- 已通过真实最小 DXF 验证 `ACAD_TABLE -> *T### display cache -> CadBlockReference -> Scene`。有有效 display cache 的表格/图签无需另造猜测式 TABLE renderer。
- 新增显式 host-controlled Xref resolver。普通 `ImportAsync` 永不自动跟随图中外部路径；只有宿主显式提供已获准的 DXF/DWG stream 时才合入 Xref。unloaded/local-cache-first、namespace isolation 与 path-safe diagnostics 均保持 fail closed；v0.12.1 不递归解析 nested Xref。

### 明确不宣称

v0.12.1 仍不宣称完整反向实现天正 BIM object model。以下 family 仍可主要依赖 raw/opaque/proxy preservation：

- `TCH_AXIS_LABEL`；
- `TCH_DRAWINGINDEX` / `TCH_INDEXPOINTER`；
- `TCH_DIMENSION2` 与 modern `TCH_DIMENSION`。

本版本改善它们的可显示 fallback，但不因此把未知 proprietary group 命名为 native semantic。既有 evidence policy、identity gate 与 modern/legacy dimension 分离规则全部保持不变。

## English

v0.12.1 is a **real-drawing-driven 2D fidelity release**. It focuses on display problems observed when v0.12.0 was compared against architectural DWG/T20 drawings: title-frame loss, axis annotations, door/window proxy detail, rotation errors, clipping, and proxy color/line-weight fidelity. It does not broaden unsupported Tianzheng native-semantic claims.

### Proxy Graphics fidelity

- Adds `ProxyText` / `ProxyUnicodeText` display fallback.
- Adds safe lightweight proxy polylines with closed state and bulges, retaining analytic arcs.
- Adds balanced planar model-transform stacks for translation, rotation and uniform scale while rejecting unsupported transforms fail closed.
- Adds safe three-point circles and Autodesk simple three-point arcs; sector/chord presentation remains an explicit non-claim.
- Adds exact transform-aware 2D proxy clipping through Scene bounds, hit testing, RenderPreparation and Win2D/Direct2D, including nested and rotated polygon clips.

### Color and line weight

- Applies explicit proxy-subentity ACI, explicit RGB/ACI true color, and standard lineweight values to emitted scene primitives.
- ByLayer / ByBlock / default states safely return to the containing custom entity's presentation instead of leaking a stale previous override.
- Foreground/None, ByDIPs and invalid states are not guessed.
- Proxy layer-index and linetype-index table resolution is intentionally not claimed in v0.12.1.

### Blocks, layouts, TABLE and Xrefs

- Preserves referenced anonymous/dynamic blocks such as `*U###` and TABLE display caches; only internal Model/Paper Space records are filtered.
- Fixes the ACadSharp angle boundary: reader angle properties are already radians, eliminating a second degree-to-radian conversion for ARC, TEXT/MTEXT, ATTRIB, INSERT, HATCH and viewport twist.
- Fixes rotation pivots for generic text, dimension text and ellipses.
- Adds a privacy-safe source-content profiler for Paper Space, viewports, anonymous blocks, TABLE cache and Xref dependencies.
- Verifies real `ACAD_TABLE -> *T### cache -> block reference -> Scene` recovery without inventing cell semantics.
- Adds an explicit host-controlled Xref resolver. Ordinary `ImportAsync` never probes stored external paths; only host-approved streams are consumed. Unloaded/cache-first behavior, deterministic namespacing and path-safe diagnostics remain enforced. Nested Xrefs are reported but not recursively resolved in v0.12.1.

### Explicit non-claims

v0.12.1 does not claim complete Tianzheng BIM reverse engineering. `TCH_AXIS_LABEL`, `TCH_DRAWINGINDEX` / `TCH_INDEXPOINTER`, and `TCH_DIMENSION2` / modern `TCH_DIMENSION` may still rely primarily on raw/opaque/proxy preservation. Better display fallback does not promote unknown proprietary fields into named semantics; the existing evidence policy remains unchanged.

- Host Contract: `SpatialViewer.CadHost >=1.0.0,<2.0.0`

## 日本語

v0.12.1 は、実際の建築 DWG/T20 と v0.12.0 の比較結果をもとにした **2D 表示 fidelity 修正版**です。図枠、軸番号、建具 proxy、rotation、clip、色・線幅の差を優先して修正し、根拠のない Tianzheng native semantic の範囲は広げません。

### Proxy Graphics

- `ProxyText` / `ProxyUnicodeText` fallback を追加。
- closed state と bulge を保持する安全な lightweight proxy polyline を追加し、arc は analytic geometry のまま維持。
- translation / rotation / uniform scale の balanced planar model-transform stack を追加。非対応 transform は fail closed。
- 三点円と Autodesk simple 三点 arc を追加。Sector / Chord は通常 arc として偽装しません。
- Scene bounds、hit test、RenderPreparation、Win2D/Direct2D を通した transform-aware 2D polygon clip を追加。nested/rotated clip も bbox 近似せず扱います。

### 色・線幅

- proxy subentity の明示 ACI、明示 TrueColor RGB/ACI、標準 lineweight を Scene primitive に適用します。
- ByLayer / ByBlock / default は包含 custom entity の表示へ安全に戻り、以前の override を漏らしません。
- Foreground/None、ByDIPs、invalid state は推測しません。
- proxy layer-index / linetype-index の table mapping は v0.12.1 の non-claim です。

### Block / Layout / TABLE / Xref

- `*U###` dynamic/anonymous block や TABLE display cache を保持し、内部 Model/Paper Space record だけを除外します。
- ACadSharp Reader の angle は既に radians であるため、ARC、TEXT/MTEXT、ATTRIB、INSERT、HATCH、viewport twist の二重変換を修正しました。
- generic text、dimension text、ellipse の rotation pivot を修正しました。
- Paper Space、viewport、anonymous block、TABLE cache、Xref dependency を path-free count だけで観測する profiler を追加しました。
- 実際の最小 DXF で `ACAD_TABLE -> *T### display cache -> block reference -> Scene` を検証済みです。
- host-controlled Xref resolver を追加。通常の `ImportAsync` は保存済み path を探索せず、host が明示的に提供した stream だけを読みます。unloaded/cache-first、namespace isolation、path-safe diagnostics を維持し、nested Xref は v0.12.1 では再帰 resolve しません。

### 明示的 non-claim

`TCH_AXIS_LABEL`、`TCH_DRAWINGINDEX` / `TCH_INDEXPOINTER`、`TCH_DIMENSION2` / modern `TCH_DIMENSION` は引き続き raw/opaque/proxy preservation が中心となる場合があります。表示 fallback の改善は proprietary raw field の semantic promotion を意味しません。既存 evidence policy は変更しません。
