## SpatialViewer.CadCore v0.7.0

### 中文
- TEXT、MTEXT、ATTRIB/ATTDEF 现在会在读取器边界之后继续保留文字样式名、字体/大字体文件名、第二对齐点、水平/垂直对齐、宽度因子、倾斜角、镜像标志，以及 MTEXT 的附着点、布局宽度与行距。
- 通用 `TextGeometry` 新增字体族、宽度缩放、倾斜、布局宽度、多行、水平/垂直锚点和 X/Y 镜像语义，既有构造方式保持兼容，可供其他格式内核复用。
- Win2D 文字渲染已贯通上述对齐、宽度、倾斜、镜像与字体族，同时继续按完整场景变换计算最终屏幕旋转和尺寸。
- 新增 CAD 字体解析器：TrueType 字体按文件名映射；SHX/shape 字体保留原始 CAD 字体身份，并显式标记 fallback，而不是把替代字体伪装成精确 SHX 字形。
- 增加常用 AutoCAD 文字控制序列归一化，包括段落换行、非断行空格以及传统 `%%` 符号转义。
- 增加 ACadSharp Writer → DXF → CadCore Reader → Scene 的真实文字端到端回归，覆盖 SHX 样式身份、对齐、镜像、倾斜、宽度因子以及 MTEXT 附着点、布局宽度、行距和 CJK TrueType fallback。
- CLR ABI 继续稳定为 `1.0.0.0`，可继续使用 SpatialViewer 0.2.x 的独立内核更新与重启激活链。
- 本版不虚假宣称完整 AutoCAD SHX 矢量字形解释器，也不宣称已经覆盖 MTEXT 的全部富文本控制码、列、堆叠分数和逐 span 字体/颜色覆盖；这些属于后续文字保真细化。

### 日本語
- TEXT、MTEXT、ATTRIB/ATTDEF で、Text Style 名、Font/Big Font ファイル名、第2 Alignment Point、水平/垂直 Justification、Width Factor、Oblique Angle、Mirror Flags、および MTEXT の Attachment Point、Layout Width、Line Spacing を Reader 境界の後も保持します。
- 共通 `TextGeometry` に Font Family、Width Scale、Oblique、Layout Width、Multiline、水平/垂直 Anchor、X/Y Mirror の意味情報を追加しました。既存 Constructor は互換のままで、他形式 Kernel からも再利用できます。
- Win2D renderer は Alignment、Width、Oblique、Mirror、Resolved Font Family を反映しつつ、最終的な画面 Rotation/Size は従来どおり完全な Scene Transform から計算します。
- CAD Font Resolver を追加しました。TrueType はファイル名から解決し、SHX/Shape Font は元の CAD Font Identity を保持したうえで Fallback を明示します。代替 Font を正確な SHX Glyph として扱いません。
- Paragraph Break、Non-breaking Space、従来の `%%` Symbol Escape など、Viewer 経路で必要な代表的 AutoCAD Text Control を正規化します。
- ACadSharp Writer → DXF → CadCore Reader → Scene の実 Round-trip Regression を追加し、SHX Style Identity、Justification、Mirror、Oblique、Width Factor、MTEXT Attachment/Layout Width/Line Spacing、CJK TrueType Fallback を検証します。
- CLR ABI は `1.0.0.0` のままで、SpatialViewer 0.2.x の独立 Kernel Update / Restart Activation 経路と互換です。
- v0.7.0 は完全な AutoCAD SHX Vector Glyph Interpreter や MTEXT 全 Rich-text Control、Columns、Stacked Fractions、Per-span Font/Color Override の完全対応をまだ主張しません。

### English
- TEXT, MTEXT, and ATTRIB/ATTDEF now retain text style name, font/big-font filenames, second alignment point, horizontal/vertical justification, width factor, oblique angle, mirror flags, plus MTEXT attachment point, layout width, and line spacing beyond the reader boundary.
- Common `TextGeometry` now carries reusable font-family, width-scale, oblique, layout-width, multiline, horizontal/vertical anchor, and X/Y mirror semantics while preserving the existing constructor surface.
- The Win2D backend applies those alignment, width, oblique, mirror, and resolved-font settings while continuing to derive final screen rotation and size from the complete scene transform.
- A CAD font resolver now maps TrueType filenames and preserves original SHX/shape-font identity with explicit fallback metadata rather than pretending a substitute font is an exact SHX glyph implementation.
- Common AutoCAD text controls used by the viewing path are normalized, including paragraph breaks, non-breaking spaces, and legacy `%%` symbol escapes.
- Adds a real ACadSharp Writer → DXF → CadCore Reader → Scene round-trip regression covering SHX style identity, justification, mirroring, oblique angle, width factor, MTEXT attachment/layout width/line spacing, and CJK TrueType fallback.
- The CLR ABI remains stable at `1.0.0.0`, preserving compatibility with the SpatialViewer 0.2.x independent kernel-update and restart-activation path.
- v0.7.0 deliberately does not claim a complete AutoCAD SHX vector-glyph interpreter or complete MTEXT rich-text coverage such as columns, stacked fractions, or every per-span font/color override.
