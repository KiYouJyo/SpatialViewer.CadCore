# SpatialViewer.CadCore v0.12.8

## 中文

v0.12.8 是针对 SpatialViewer v0.3.8 湘源控规实机验收中发现的 **用地色块缺失** 问题的定向修复版本。

### 修复内容

- ObjectARX `ProxyPolygon` 现在恢复其面填充语义：Scene 中的 `PolygonGeometry` 会使用当前有效 Proxy 颜色作为 `Fill`，不再只画轮廓。
- `ProxySubentColor` / TrueColor 等 primitive color override 会同时作用于 polygon 的描边和填充。
- 普通 `ProxyPolyline`、closed `ProxyLwPolyline`、Circle、Arc 仍保持线框；Mesh/Shell 仍只恢复可信边线，不会被误填充。

### 实机问题对应

在 v0.3.8 + CadCore v0.12.7 中，湘源控规图的地块轮廓、道路和图例色块都能够显示，但主图中的用地地块只剩彩色边界，面色没有显示。

CadCore 原本已经把 ObjectARX `ProxyPolygon` 解析成 `PolygonGeometry`，Win2D 也支持 polygon fill；问题出在中间 Scene translation 只保留了 `Stroke`，`Fill` 始终为 null。v0.12.8 修复这一断点。

### 安全边界

- 该修复恢复的是通用 ObjectARX Proxy Polygon 显示语义，不把任意 polygon 认定为湘源地块。
- 不新增或猜测湘源 proprietary class / raw field semantic。
- v0.13 原生湘源地块语义计划不因此提前完成。

### 发布契约

- Product/File/Informational version: `0.12.8`
- CLR ABI: `1.0.0.0`
- Host Contract: `SpatialViewer.CadHost >=1.0.0,<2.0.0`
- Release manifest schema: `2`

## English

v0.12.8 is a focused real-device fix for the missing Xiangyuan land-use color blocks observed in SpatialViewer v0.3.8.

ObjectARX `ProxyPolygon` primitives now preserve filled-polygon presentation in the scene layer: the effective proxy color is used for both stroke and fill, including safe ACI/TrueColor primitive overrides. Polyline/LwPolyline, circle/arc and mesh/shell edge fallback remain unfilled.

The regression was caused by a scene-translation gap: CadCore already mapped `ProxyPolygon` to `PolygonGeometry`, and the renderer already supported filling, but the proxy effective color was assigned only to `Stroke`, leaving `Fill=null`.

This restores generic ObjectARX display semantics only and does not infer Xiangyuan parcel semantics.

Compatibility remains ABI `1.0.0.0`, `SpatialViewer.CadHost >=1.0.0,<2.0.0`, manifest schema `2`.

## 日本語

v0.12.8 は SpatialViewer v0.3.8 の湘源控規実機検証で確認された **用途地域の色面が表示されない問題**の修正版です。

ObjectARX `ProxyPolygon` は、現在の effective proxy color を stroke と fill の両方へ適用し、outline-only ではなく本来の filled polygon として表示されます。ACI/TrueColor override も fill に反映されます。一方、Polyline / closed LwPolyline / Circle / Arc、Mesh/Shell edge fallback は従来どおり塗りつぶしません。

この修正は一般的な ObjectARX proxy polygon 表示の復元であり、polygon を湘源 parcel と推測する semantic 対応ではありません。

互換契約は ABI `1.0.0.0`、`SpatialViewer.CadHost >=1.0.0,<2.0.0`、manifest schema `2` を維持します。
