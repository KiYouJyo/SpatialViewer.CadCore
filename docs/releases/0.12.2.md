# SpatialViewer.CadCore v0.12.2

## 中文

v0.12.2 是在 v0.12.1 实图对照基础上的 **建筑轴网/尺寸显示保真修复**。本版本聚焦标准 AutoCAD DIMENSION/DIMSTYLE 显示，不扩大天正 proprietary native-semantic 声明。

### 修复

- 识别 AutoCAD 常见的 `_Oblique` / `ARCHTICK` / `_ArchTick` 建筑斜线端点，并将其实际渲染为单条 45° tick，不再只保留 DIMBLK 名称后退化为通用 V 形箭头。
- 支持两端分别指定 arrow block；已知建筑斜线与未知自定义箭头可在同一尺寸中安全共存。
- 未知 custom DIMBLK 继续走既有保守 generic-arrow fallback，不猜测任意自定义块几何。
- DIMENSION 文字方向归一到可读半平面，修复水平尺寸 `2250` 等因源旋转等价于 180° 而倒置的问题；普通 TEXT/MTEXT 的原始旋转不受影响。
- 新增针对 `_Oblique` / `ARCHTICK`、两端混合箭头、未知 custom block、180°/270° 文字方向的回归测试。

### 语义边界

本版本不把显示修复当作天正私有字段证据。以下对象仍保持既有 raw/opaque/proxy 与 evidence-policy 边界：

- `TCH_AXIS_LABEL`
- `TCH_DRAWINGINDEX` / `TCH_INDEXPOINTER`
- `TCH_DIMENSION2`
- modern `TCH_DIMENSION`

### 发布契约

- Product / FileVersion / InformationalVersion：`0.12.2`
- CLR ABI：`1.0.0.0`
- Host Contract：`SpatialViewer.CadHost >=1.0.0,<2.0.0`
- Release manifest schema：`2`
- 发布候选门禁：Cad `267/267`、Core `22/22`、Rendering `24/24`；Debug / Release / benchmark 均通过。

> 整套图框/标题栏缺失的另一根因位于 SpatialViewer 宿主：CadCore 已有 Paper Space/Layout scene，但旧 Viewer 固定渲染 Model Space。该宿主修复与本内核版本配套接入。

## English

v0.12.2 is a **building-grid and dimension display-fidelity patch** driven by real drawing comparison after v0.12.1. It targets standard AutoCAD DIMENSION/DIMSTYLE presentation and does not broaden unsupported Tianzheng proprietary semantic claims.

### Fixed

- Recognizes common AutoCAD `_Oblique` / `ARCHTICK` / `_ArchTick` architectural end marks and renders each as an actual single 45-degree tick instead of retaining only DIMBLK metadata and falling back to a generic V arrow.
- Supports separate first/second arrow-block identities, including safe mixed architectural-tick and unknown-custom fallback behavior.
- Unknown custom DIMBLK geometry remains on the conservative generic-arrow path rather than being guessed.
- Normalizes semantic DIMENSION text to a readable half-plane, fixing values such as `2250` that were rendered upside down when the source orientation was equivalent to 180 degrees. Ordinary TEXT/MTEXT rotations remain authored as-is.
- Adds focused regression tests for architectural ticks, mixed arrow blocks, unknown custom blocks, and 180/270-degree dimension-text orientation.

### Semantic boundary

The following Tianzheng families remain under the existing raw/opaque/proxy and evidence-policy boundary: `TCH_AXIS_LABEL`, `TCH_DRAWINGINDEX`, `TCH_INDEXPOINTER`, `TCH_DIMENSION2`, and modern `TCH_DIMENSION`.

### Release contract

- Product/File/Informational version: `0.12.2`
- CLR ABI: `1.0.0.0`
- Host Contract: `SpatialViewer.CadHost >=1.0.0,<2.0.0`
- Release manifest schema: `2`
- Candidate gate: Cad `267/267`, Core `22/22`, Rendering `24/24`; Debug, Release and benchmark builds pass.

The separate full-sheet border/title-block symptom is addressed in the SpatialViewer host by selecting an imported Paper Space layout instead of always forcing Model Space.

## 日本語

v0.12.2 は v0.12.1 の実図面比較を受けた **建築グリッド・寸法表示 fidelity 修正版**です。対象は標準 AutoCAD DIMENSION / DIMSTYLE 表示であり、天正 proprietary native semantic の未検証 field を追加宣言しません。

### 修正

- AutoCAD で一般的な `_Oblique` / `ARCHTICK` / `_ArchTick` を認識し、generic V-arrow ではなく実際の 45° architectural tick として描画します。
- first / second arrow block を別々に保持し、architectural tick と未知 custom arrow の混在にも安全に対応します。
- 未知 custom DIMBLK は従来の conservative generic-arrow fallback を維持し、任意 block geometry を推測しません。
- semantic DIMENSION text を readable half-plane に正規化し、180° 相当の回転で `2250` 等が上下逆になる問題を修正します。通常の TEXT / MTEXT の回転には影響しません。
- architectural tick、mixed arrow、unknown custom block、180°/270° text orientation の回帰テストを追加しました。

### semantic boundary

`TCH_AXIS_LABEL`、`TCH_DRAWINGINDEX` / `TCH_INDEXPOINTER`、`TCH_DIMENSION2`、modern `TCH_DIMENSION` は従来どおり raw/opaque/proxy と evidence policy の境界を維持します。

### release contract

- Product / File / Informational version: `0.12.2`
- CLR ABI: `1.0.0.0`
- Host Contract: `SpatialViewer.CadHost >=1.0.0,<2.0.0`
- Release manifest schema: `2`
