# SpatialViewer.CadCore v0.12.3

## 中文

v0.12.3 是基于 v0.12.2 实图对照的 **图框文字、坐标标注与 DIMSTYLE 保真修复**。本版本继续只修复有标准 AutoCAD / ACadSharp 证据支持的显示路径，不扩大天正私有语义声明。

### 修复

- 修复 Ordinate DIMENSION 的错误几何重建。旧实现把 `FeatureLocation -> LeaderEndpoint -> DefinitionPoint` 直接连线，会在 DefinitionPoint 与实际图纸相距很远时产生两根极长直角线并污染 Fit Extents。现在按 AutoCAD/ACadSharp 的可见 jog 规则，仅由 FeatureLocation、LeaderEndpoint、HorizontalDirection 与 ordinate axis 重建三段折线，不再把 DefinitionPoint 当作可见端点。
- DIMENSION group 11 / `TextMiddlePoint` 现在按真正的 Middle-Center 锚点渲染，修复 `2250` 等标注文字整体偏移。
- `DIMBLK` 在 `DIMSAH` / separate-arrow 模式下会作为空 first/second slot 的共享后备值，恢复 `_ARCHTICK` / `_Oblique` 建筑斜线分界点。
- DIMCLRD、DIMCLRE、DIMCLRT 独立保留并分别应用到尺寸线、尺寸界线和尺寸文字，不再把三个组件错误压成同一种颜色。
- 未能直接使用 SHX glyph stream 的中文传统 CAD 文字 fallback 从 UI sans-serif 调整为更接近传统建筑图纸字面度量的 SimSun；日文 SHX fallback 使用 MS Gothic。真实 SHX 向量字体可用时仍优先走原有向量字形路径。
- 新增针对 ordinate 远端 DefinitionPoint、architectural tick 共享后备、DIMENSION 中心锚点、DIMSTYLE 独立组件颜色和中文 SHX fallback 的回归测试。

### 语义边界

本版本没有通过视觉结果反推天正私有字段。`TCH_AXIS_LABEL`、`TCH_DRAWINGINDEX` / `TCH_INDEXPOINTER`、`TCH_DIMENSION2` 与 modern `TCH_DIMENSION` 仍保持既有 raw/opaque/proxy evidence-policy 边界。

### 发布契约

- Product / FileVersion / InformationalVersion：`0.12.3`
- CLR ABI：`1.0.0.0`
- Host Contract：`SpatialViewer.CadHost >=1.0.0,<2.0.0`
- Release manifest schema：`2`
- 发布候选门禁：Cad `272/272`、Core `22/22`、Rendering `24/24`；Debug / Release / benchmark 均要求通过。

## English

v0.12.3 is a **title-block text, ordinate annotation, and DIMSTYLE fidelity patch** driven by real-drawing comparison after v0.12.2.

### Fixed

- Reconstructs ordinate DIMENSION jog geometry from FeatureLocation, LeaderEndpoint, HorizontalDirection, and ordinate axis instead of drawing visible segments to DefinitionPoint. This removes the giant perpendicular L-shaped lines that could also corrupt Fit Extents.
- Treats DIMENSION group 11 / `TextMiddlePoint` as a true middle-center anchor, fixing displaced values such as `2250`.
- Falls back from empty first/second arrow slots to the shared `DIMBLK` in separate-arrow mode, restoring `_ARCHTICK` / `_Oblique` architectural end marks.
- Preserves DIMCLRD, DIMCLRE, and DIMCLRT independently and applies them to dimension lines, extension lines, and text respectively.
- Uses a print-oriented SimSun fallback for unresolved legacy Chinese SHX text and MS Gothic for Japanese SHX text while retaining the existing vector-SHX path whenever real glyph layout is available.
- Adds focused regressions for remote ordinate datum points, shared architectural ticks, DIMENSION midpoint anchoring, independent DIMSTYLE component colors, and CJK SHX fallback.

### Semantic boundary

No proprietary Tianzheng field is promoted from visual inference. `TCH_AXIS_LABEL`, `TCH_DRAWINGINDEX` / `TCH_INDEXPOINTER`, `TCH_DIMENSION2`, and modern `TCH_DIMENSION` remain under the existing raw/opaque/proxy evidence policy.

- Release manifest schema: `2`

## 日本語

v0.12.3 は v0.12.2 の実図面比較に基づく **図枠文字・ordinate 寸法・DIMSTYLE fidelity 修正版**です。

### 修正

- Ordinate DIMENSION の表示 jog を FeatureLocation、LeaderEndpoint、HorizontalDirection、ordinate axis から再構成し、DefinitionPoint へ可視線を引かないようにしました。これにより図面外まで伸びる巨大な直角 L 線と Fit Extents 汚染を解消します。
- DIMENSION group 11 / `TextMiddlePoint` を middle-center anchor として扱い、`2250` 等の文字位置ずれを修正します。
- separate-arrow 時に first/second slot が空の場合、shared `DIMBLK` にフォールバックし、`_ARCHTICK` / `_Oblique` の建築 tick を復元します。
- DIMCLRD、DIMCLRE、DIMCLRT を独立保持し、寸法線・補助線・寸法文字へ個別に適用します。
- 実 SHX glyph layout が利用できない中国語 SHX は SimSun、日本語 SHX は MS Gothic を表示 fallback とし、実際の SHX vector path が利用可能な場合は従来どおりそちらを優先します。
- 上記 real-drawing failure mode に対する回帰テストを追加しました。

### semantic boundary

`TCH_AXIS_LABEL`、`TCH_DRAWINGINDEX` / `TCH_INDEXPOINTER`、`TCH_DIMENSION2`、modern `TCH_DIMENSION` は従来どおり raw/opaque/proxy evidence-policy の境界を維持します。

### release contract

- Product / File / Informational version: `0.12.3`
- CLR ABI: `1.0.0.0`
- Host Contract: `SpatialViewer.CadHost >=1.0.0,<2.0.0`
- Release manifest schema: `2`
- Candidate gate: Cad `272/272`、Core `22/22`、Rendering `24/24`、Debug / Release / benchmark PASS を必須とします。
