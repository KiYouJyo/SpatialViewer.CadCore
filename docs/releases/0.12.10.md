# SpatialViewer.CadCore v0.12.10

## 中文

v0.12.10 是面向湘源控规实图的 **Proxy Graphics 取证诊断版本**。

连续实机验证已经排除了当前 CadCore 已覆盖的标准填充路径：

- ProxyPolygon；
- ProxySubentFillon；
- 平面 ProxyMesh / ProxyShell face；
- face color / visibility；
- Win2D polygon fill。

但同一张湘源图仍只有彩色轮廓，没有主用地色面。因此本版不再继续猜测“哪种闭合几何应该填色”，而是向 Proxy Graphics 解析入口前移一层，直接记录 ACadSharp 尚未实现的 raw command 类型。

### 新增

- 扫描 ACadSharp 每个 entity template 中保留的原始 Proxy Graphics stream framing。
- 只读取：
  - command type id；
  - record size；
  - sequence / same-type occurrence；
  - 当前 ACadSharp 3.7.1 是否已知该 command。
- 每个 custom entity 新增匿名结构 metadata：
  - raw command 总数；
  - known / unknown 数量；
  - type signature；
  - Unknown type id 列表；
  - malformed / truncated 状态。
- 文档级新增 `CAD_PROXY_GRAPHICS_UNKNOWN_COMMANDS` 诊断，聚合未知 command 数量和 type id。

### 为什么需要这一版

ACadSharp 3.7.1 当前 Proxy Graphics 枚举只覆盖既定的一组 command，reader 对未实现 type 会直接跳过。其源码中也存在对未实现 Type 51 的历史注释。

因此，如果湘源用地色块通过 ACadSharp 尚未实现的 Proxy command 输出，那么 CadCore 后续即使完整支持 Polygon / Mesh / Shell，也只会得到剩余轮廓；真正的填充命令已经在 reader 入口处消失。

v0.12.10 的目的就是用实图确认这一点。

### 隐私边界

command scanner **不会保存 payload**。

报告不包含：

- 原 DWG 文件名或路径；
- entity / target handle；
- layer name；
- 坐标；
- 颜色值；
- 地块编号或规划指标；
- 文字内容；
- raw DWG / DXF / Proxy Graphics bytes。

Unknown type id 只视为匿名结构证据。本版不会把 type 39+、51 或其他编号直接解释为 polyPolygon、solid fill、gradient fill、hatch 或湘源专用语义。

### 发布契约

- Product/File/Informational version: `0.12.10`
- CLR ABI: `1.0.0.0`
- Host Contract: `SpatialViewer.CadHost >=1.0.0,<2.0.0`
- Release manifest schema: `2`

## English

v0.12.10 is a **raw ObjectARX Proxy Graphics diagnostic release** for the real Xiangyuan drawing that remains outline-only after all currently supported standard fill paths were restored.

The release inspects the raw Proxy Graphics record framing retained inside ACadSharp entity templates and records only command type ID, record size, sequence/occurrence, and whether ACadSharp 3.7.1 currently recognizes the command.

Unknown command IDs and aggregate counts are exposed as privacy-safe structural evidence. Raw payload bytes, handles, paths, coordinates, colors and text are never emitted.

This release intentionally does not assign semantics to unknown IDs such as 39+ or 51. Its purpose is to identify whether the missing Xiangyuan fill is being discarded by the upstream proxy reader before CadCore receives the drawable stream.

ABI remains `1.0.0.0`; host contract and manifest schema are unchanged.

## 日本語

v0.12.10 は、標準的な ProxyPolygon / Mesh / Shell / FillOn 対応後も outline-only のままである湘源控規実図面のための **raw ObjectARX Proxy Graphics 診断版**です。

ACadSharp entity template に保持されている raw Proxy Graphics stream の framing のみを調査し、command type ID、record size、sequence / occurrence、ACadSharp 3.7.1 が既知かどうかだけを記録します。

payload byte、handle、file path、座標、色値、文字列は出力しません。Unknown type ID は構造証拠としてのみ扱い、type 39+ / 51 等に speculative semantic を与えません。

ABI `1.0.0.0`、Host Contract、manifest schema は変更ありません。
