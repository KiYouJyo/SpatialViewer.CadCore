# SpatialViewer.CadCore v0.12.10

## 中文

v0.12.10 将上一轮已经进入主干的 ObjectARX Proxy Graphics 原始命令诊断能力收束为正式版本，并作为 SpatialViewer v0.4.2“CAD 兼容性报告”的内核数据来源。

### 新增

- 新增隐私安全的 raw Proxy Graphics command scanner，仅保留命令结构信息：type ID、record size、出现次数以及 ACadSharp 已知/未知分类。
- 从 ACadSharp template 数据以及 DWG 读取后的代理图形数据中捕获命令 framing，并把 inventory 挂接到 reader-independent custom entity metadata。
- 新增文档级汇总诊断：
  - raw command capture 是否受支持/失败；
  - malformed / truncated stream 数量；
  - unknown-command entity / command 总数；
  - unknown type IDs。
- 增加未知 enum gap、非法 record size、截断命令流、确定性 signature 与“不会保留原始 payload bytes”的回归测试。

### 与 SpatialViewer v0.4.2 的关系

v0.4.2 可以直接从已载入的 `CadDocument` 导出隐私安全 CAD 兼容性报告，用这些结构证据定位湘源及其他 ObjectARX 图纸中仍未翻译的代理命令，而不再依赖继续猜测显示 primitive。

### 隐私与兼容性

- 不保留 raw proxy payload bytes、图纸文件名/路径、文字、坐标、handle、图层名或 proprietary property values。
- unknown command 只作为结构证据，不自动提升为任何 proprietary semantic。
- Product/File/Informational version: `0.12.10`
- CLR ABI: `1.0.0.0`
- Host Contract: `SpatialViewer.CadHost >=1.0.0,<2.0.0`
- Release manifest schema: `2`

## English

v0.12.10 formally ships the raw ObjectARX Proxy Graphics command inventory already landed on main and provides the kernel-side evidence source for SpatialViewer v0.4.2 CAD compatibility reports.

The release adds a privacy-safe raw proxy-command scanner that retains only command framing/type IDs/sizes/counts and known-vs-unknown classification, captures that inventory across the ACadSharp/DWG read path, and surfaces aggregate malformed/truncated/unknown-command diagnostics. Regression coverage verifies deterministic signatures and that raw payload bytes are never retained.

SpatialViewer v0.4.2 can export these structural diagnostics from the loaded reader-independent document to investigate unsupported ObjectARX graphics without guessing proprietary semantics.

ABI remains `1.0.0.0`; Host Contract and release manifest schema are unchanged.
