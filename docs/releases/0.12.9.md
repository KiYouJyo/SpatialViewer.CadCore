# SpatialViewer.CadCore v0.12.9

## 中文

v0.12.9 是第二轮湘源控规用地色面实机修复。v0.12.8 已恢复通用 `ProxyPolygon` 填充，但实图仍只有轮廓；继续追查后确认 CadCore 还存在更深一层的 ObjectARX Proxy Graphics 信息丢失。

### 根因

ACadSharp 已经能够读取：

- `ProxySubentFillon`：ObjectARX 当前 fill type；
- `ProxyMesh.FaceTraits`；
- `ProxyShell.FaceTraits`；
- face color / layer / marker / visibility / normal。

但 CadCore v0.12.8 之前：

1. 没有处理 `ProxySubentFillon`；
2. Mesh/Shell 只转换成 `CadProxyEdgeSet`；
3. FaceTraits 与 face geometry 完全没有进入 reader-independent model。

因此如果湘源地块以 filled shell/mesh 输出，结果必然是“边界正确、面色全部丢失”。

### v0.12.9 修复

- `CadProxyTraits` 新增显式 fill state。
- 读取并持续应用 `ProxySubentFillon`。
- 当 fill 明确开启且 Mesh/Shell 严格共面、face 结构合法时，保留为 `CadProxySurfaceSet`：
  - face points；
  - face ACI color；
  - layer reference；
  - marker；
  - visibility；
  - 原始 edge fallback。
- Scene 中先绘制 filled face，再绘制原 edge，保留边界表现。
- FaceTraits 不完整、数量不匹配、normal 非平面、顶点非法或面退化时不猜测，退回 edge-only。
- transform 与 clip scope 同样支持 filled surface。
- 显式 `FillNever` 会关闭 ProxyPolygon 填充；Polyline 即使闭合也继续不填充。
- surface face geometry 已加入隐私安全 A/B geometry evidence。

### 兼容性

- Product/File/Informational version: `0.12.9`
- CLR ABI: `1.0.0.0`
- Host Contract: `SpatialViewer.CadHost >=1.0.0,<2.0.0`
- Release manifest schema: `2`

本版仍然是通用 ObjectARX display-fidelity 修复，不声明任何 proprietary 湘源地块 class 或字段语义。

## English

v0.12.9 is the second real-device fix for missing Xiangyuan land-use fills.

After v0.12.8 restored generic `ProxyPolygon` filling, the real drawing still rendered as outlines only. The deeper gap was that ACadSharp already parses ObjectARX `ProxySubentFillon` and mesh/shell face traits, while CadCore discarded fill state and collapsed all mesh/shell graphics to edge-only fallback.

v0.12.9 retains explicit fill state and maps strictly planar, structurally valid filled meshes/shells to `CadProxySurfaceSet`, preserving face colors/visibility plus original edge fallback. Invalid or non-planar face evidence falls back to edges rather than guessing geometry.

ABI remains `1.0.0.0`; host contract and manifest schema are unchanged.

## 日本語

v0.12.9 は湘源控規の用途色面に対する第2回実機修正版です。

v0.12.8 で `ProxyPolygon` の塗りつぶしを復元しても実図面は outline-only のままでした。調査の結果、ACadSharp は `ProxySubentFillon` と Mesh/Shell の FaceTraits を既に解析している一方、CadCore が fill state と face geometry を捨て、edge-only に変換していたことを確認しました。

本版では、fill が明示的に有効で、厳密に平面かつ構造が正しい Mesh/Shell の face を `CadProxySurfaceSet` として保持し、face color / visibility と元の edge fallback を描画します。不正・非平面データは推測せず edge-only に戻します。

ABI `1.0.0.0`、Host Contract、manifest schema は変更ありません。
