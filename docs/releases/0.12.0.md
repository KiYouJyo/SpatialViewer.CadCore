# SpatialViewer.CadCore v0.12.0

## 中文

v0.12.0 是 CadCore 的 **天正建筑二维实用兼容**里程碑。它在 v0.11.0 已建立的 custom-object preservation / Proxy Graphics fallback 基础上，开始把有充分证据的天正对象字段提升为 reader-independent native semantics，同时保留严格的 fail-closed 原则：未知字段不猜、不同对象 identity 不强行 alias、证据不足时继续依赖 raw/proxy preservation。

本版本的发布目标是让 SpatialViewer 尽早接入当前天正兼容内核，用真实 DWG/T20 图纸的显示结果驱动 0.12.x 后续修复；它**不宣称完整反向实现天正 BIM 对象模型**。

### 新增天正 native semantics

- `TCH_WALL`：达到 **Drawable2D**。恢复直墙起终点、左右厚度，以及证据允许时的标高/高度，并可生成 native wall outline。
- `TCH_OPENING`：达到 **Partial**。保留 opening anchor、可选 Z、opening→wall relationship，并增加证据支持的门窗编号字段；宽高、窗台高、开启方式与完整 native geometry 仍不做无证据声明。
- `TCH_SPACE`：达到 **Partial**。恢复 anchor、房间名称与编号；面积、体积、周长、边界等继续保持 raw-only，避免把计算字段或未知 slot 错命名为语义字段。
- `TCH_ELEVATION`：达到 **Partial**。恢复 anchor、标高文本以及证据允许时的出图比例；符号完整几何、方向、样式等仍未宣称完整支持。
- `TCH_DRAWINGNAME`：达到 **Partial**。恢复图名文字，不把插入点、下划线、比例或索引关系顺手推断成已支持字段。
- `TCH_COLUMN`：达到 **Partial**。恢复公开证据明确的柱插入点；截面宽高、形状、转角、柱高与完整轮廓继续保持未知。
- `TCH_LINESTAIR` / `TCH_RECTSTAIR`：达到 **Partial**。恢复证据明确的踏步高度；踏步宽、步数、梯段/梯井宽、总高等仍不做猜测式解析。

### 兼容与研究基础设施

- 新增 privacy-safe DXF A/B differ：只输出发生变化的 group index / code / occurrence，不输出实际 raw value。
- 新增 privacy-safe DWG A/B differ：只输出 changed byte ranges / length relation，不输出 raw bytes、handle、路径或 object-section offset。
- 新增 repeatability consensus：要求独立 A/B observation 的稳定交集，单次偶然变化不能直接成为 semantic candidate。
- 新增 entity-level identity gate：对象 DXF identity、已知 C++ class/application identity 不一致时，在产生 semantic candidate 前 fail closed。
- 新增 Tianzheng schema corpus 与 JSON merge/validation，用于跨样本汇总 class/group/subclass/reference signature，而不是把 corpus 本身伪装成 native semantic。
- 新增 case-bound `TCHPLAN / TCHDIFF / TCHSIG / TCHRUN` AutoLISP 工作流。`TCHRUN` 会在 identity、subclass profile 与 ordered group layout 全部一致后才输出原子 bundle。
- 新增 `TianzhengExportProbe.ps1`，只读解析本机 Tianzheng ARX 的 PE export table；不加载/执行目标模块、不读取图纸、不输出安装路径，用于辅助确认 native class/API identity。
- 对现代公开资料中的 `TCH_DIMENSION` 与历史 `TCH_DIMENSION2` 建立独立 identity-drift 研究线，明确禁止无证据 alias。

### Practical compatibility 发布策略

v0.12.0 不再要求所有 Tianzheng 核心类别都先完成 Partial native semantic 才允许发布。对于看图器产品，安全识别、对象保留、可信 Proxy Graphics fallback 与真实显示效果具有更高的当前优先级。

因此以下类别在 v0.12.0 中仍可能主要依赖 opaque/raw/proxy preservation：

- `TCH_AXIS_LABEL` family；
- `TCH_DRAWINGINDEX` / `TCH_INDEXPOINTER` family；
- `TCH_DIMENSION2` 及现代 `TCH_DIMENSION` family。

这三类不再阻止 v0.12.0 发布，但本版本**不宣称它们已完成 native semantic decoding**。后续若要提升为 named semantic，仍必须满足既有 evidence policy：可信 raw-field mapping、真实 Reader regression、必要的独立 observation，以及 malformed/duplicate/truncated/identity-mismatch 等 fail-closed 回归。

### 回归与发布契约

- 发布前完整运行 Debug / Release build、benchmark build 与全部测试。
- Tianzheng PE export probe 通过真实 Windows PE export table 正向测试，并验证 path redaction 与 malformed-PE fail-closed。
- Product / FileVersion / InformationalVersion 更新为 `0.12.0`。
- CLR ABI 保持 `1.0.0.0`。
- Host Contract 保持 `SpatialViewer.CadHost >=1.0.0,<2.0.0`。
- Release manifest schema 保持 `2`。
- 官方资产继续提供 `CadCore-v0.12.0-x64.zip`、`cadcore-release.json` 与 `SHA256SUMS.txt`。

### 后续方向

0.12.x 开始优先由真实图纸体感驱动：不可见对象、错位、颜色/字体/比例不一致、Proxy Graphics 缺失、性能回归等问题优先修复。更完整的 axis/index/dimension native semantics 与更深层 Tianzheng BIM 参数解析继续迭代，不再阻塞本次实用兼容版本交付。

## English

v0.12.0 is the **Tianzheng Architecture 2D practical-compatibility** milestone. Building on v0.11.0 custom-object preservation and Proxy Graphics fallback, CadCore now promotes evidence-backed Tianzheng fields into reader-independent native semantics while keeping strict fail-closed boundaries: unknown fields are not guessed, different identities are not silently aliased, and unsupported objects remain preserved through raw/proxy paths.

This release intentionally prioritizes getting the current kernel into SpatialViewer so real DWG/T20 display behavior can drive 0.12.x. It does **not** claim a complete reverse implementation of the Tianzheng BIM object model.

### Native Tianzheng semantics added

- `TCH_WALL` reaches **Drawable2D**, including evidence-backed straight-wall parameters and native wall-outline generation.
- `TCH_OPENING`, `TCH_SPACE`, `TCH_ELEVATION`, `TCH_DRAWINGNAME`, `TCH_COLUMN`, `TCH_LINESTAIR` and `TCH_RECTSTAIR` reach **Partial** semantics for the specific fields backed by external evidence.
- Unknown width/height/style/geometry/BIM properties remain explicit non-claims instead of being inferred from plausible values.

### Compatibility and research infrastructure

- Privacy-safe DXF and DWG A/B differencing without emitting raw values/bytes, handles or paths.
- Repeatability consensus that requires stable candidates across independent observations.
- Entity-level identity gating before any semantic candidate is accepted.
- Validated Tianzheng schema corpus and JSON merge workflow for structural research.
- Case-bound `TCHPLAN / TCHDIFF / TCHSIG / TCHRUN` AutoLISP workflow with atomic bundle output only after identity/subclass/layout validation.
- Host-only `TianzhengExportProbe.ps1` that parses the PE export table without loading/executing the ARX or reading drawings, and emits only a path-free module fingerprint plus filtered native symbols.
- Separate research handling for modern `TCH_DIMENSION` versus historical `TCH_DIMENSION2`; no unsupported alias is introduced.

### Practical-compatibility release policy

v0.12.0 no longer requires every historically scoped Tianzheng category to reach Partial native semantics before shipping. Safe identification, object preservation, trustworthy proxy fallback and real viewing behavior are the current product priority.

The following families may therefore remain primarily opaque/raw/proxy-backed in v0.12.0:

- `TCH_AXIS_LABEL`;
- `TCH_DRAWINGINDEX` / `TCH_INDEXPOINTER`;
- `TCH_DIMENSION2` and modern `TCH_DIMENSION`.

Their incomplete native decoding does not block this release, but v0.12.0 does **not** claim native semantic completion for them. Future named-semantic promotion still requires the unchanged evidence policy: trustworthy raw-field mapping, real Reader regression, independent observations where required, and fail-closed negative tests.

### Release contract

- Product/File/Informational version: `0.12.0`
- CLR ABI: `1.0.0.0`
- Host Contract: `SpatialViewer.CadHost >=1.0.0,<2.0.0`
- Release manifest schema: `2`
- Release assets: `CadCore-v0.12.0-x64.zip`, `cadcore-release.json`, `SHA256SUMS.txt`

0.12.x development will be driven primarily by real drawing behavior: missing objects, placement errors, color/text/scale fidelity, proxy gaps and performance regressions. Deeper Tianzheng semantic decoding continues incrementally without blocking this practical release.

## 日本語

v0.12.0 は **天正建築 2D practical compatibility（実用互換）** のマイルストーンです。v0.11.0 の custom-object preservation / Proxy Graphics fallback を土台に、外部根拠が十分な Tianzheng field を reader-independent native semantic に昇格しました。一方で、未知 field を推測しない、異なる identity を silent alias しない、証拠不足時は raw/proxy preservation を維持するという fail-closed 原則は変えません。

本リリースは現在の kernel を SpatialViewer に早期統合し、実際の DWG/T20 表示を 0.12.x の優先順位に使うことを目的とします。天正 BIM object model 全体の完全な逆実装を宣言するものではありません。

### 追加された native semantic

- `TCH_WALL` は **Drawable2D** に到達し、根拠のある straight-wall parameter と native wall outline を扱います。
- `TCH_OPENING`、`TCH_SPACE`、`TCH_ELEVATION`、`TCH_DRAWINGNAME`、`TCH_COLUMN`、`TCH_LINESTAIR`、`TCH_RECTSTAIR` は、外部 evidence が明確な field に限って **Partial** semantic に到達しました。
- width / height / style / geometry / BIM property の未知部分は推測せず non-claim のまま保持します。

### 互換・研究基盤

- raw value/byte、handle、path を出力しない privacy-safe DXF / DWG A/B diff。
- 複数 independent observation で安定する candidate のみ残す repeatability consensus。
- semantic candidate 前の entity-level identity gate。
- Tianzheng schema corpus と validated JSON merge。
- identity / subclass / ordered group layout を検証後だけ atomic bundle を出力する `TCHPLAN / TCHDIFF / TCHSIG / TCHRUN`。
- ARX を load/execute せず drawing も読まない `TianzhengExportProbe.ps1`。path-free fingerprint と関連 native symbol のみ出力します。
- modern `TCH_DIMENSION` と historical `TCH_DIMENSION2` を別研究線として保持し、根拠のない alias は行いません。

### practical compatibility release policy

v0.12.0 は、歴史的 scope の全 Tianzheng category が Partial native semantic に到達することをリリース必須条件にはしません。安全な識別、object preservation、信頼できる Proxy Graphics fallback、実際の viewer 表示を現在の product priority とします。

そのため次の family は v0.12.0 でも opaque/raw/proxy preservation が中心の場合があります。

- `TCH_AXIS_LABEL`；
- `TCH_DRAWINGINDEX` / `TCH_INDEXPOINTER`；
- `TCH_DIMENSION2` と modern `TCH_DIMENSION`。

これらは v0.12.0 release を阻止しませんが、native semantic 完了を宣言しません。将来 named semantic に昇格する場合は、従来の evidence policy――trustworthy raw-field mapping、real Reader regression、必要な independent observation、fail-closed negative test――を引き続き必須とします。

### release contract

- Product/File/Informational version: `0.12.0`
- CLR ABI: `1.0.0.0`
- Host Contract: `SpatialViewer.CadHost >=1.0.0,<2.0.0`
- Release manifest schema: `2`
- Assets: `CadCore-v0.12.0-x64.zip`, `cadcore-release.json`, `SHA256SUMS.txt`

0.12.x は実図面での非表示、位置ずれ、色/文字/scale fidelity、proxy gap、performance regression を優先して修正します。より深い Tianzheng semantic decoding は段階的に継続します。
