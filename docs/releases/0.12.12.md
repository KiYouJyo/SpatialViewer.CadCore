# SpatialViewer.CadCore v0.12.12

## 中文

v0.12.12 针对 0.12.11 实机报告继续推进湘源 `LZX_LAND` 的显示完整度。

### 实机证据

最新兼容性报告已经确认同一张图中：

- 湘源 `LZX_LAND / AcdbLzxLand`：115 个；
- `ProxyGraphics`：115/115；
- translated：115；
- unsupported：0；
- 每个地块仅包含 `SubentColor + SubentMarker + SubentFillon + LwPolyine`；
- 没有 Polygon / Mesh / Shell / Hatch / Text。

因此 0.12.11 已把真实代理轮廓完整读出，但代理流本身没有可用于通用面填充或指标文字的 primitive。

### 新增显示兜底

仅在同时满足以下条件时：

1. 明确识别为 Xiangyuan；
2. class 为 `LZX_LAND / AcdbLzxLand`；
3. 位于 `YD-*` CAD 图层；
4. 恰好只有一个闭合 `CadProxyLwPolyline`；
5. 当前没有 native semantic decoder；

CadCore 会在原始代理轮廓下方生成一个**显示用途**的地块底色，颜色直接使用该对象所在 CAD 图层已经解析出的实际颜色。

原始 Proxy Graphics 轮廓仍保持在上层，因此边界的 `SubentColor`、marker、bulge 曲线等不会被覆盖。

### 不猜属性

该兜底不把 LwPolyline 改写为通用 ObjectARX Polygon，也不声称解码了湘源原生字段。它不会生成或猜测：

- 地块编号；
- 用地代码/用地性质文字；
- 容积率；
- 建筑密度；
- 绿地率；
- 建筑高度；
- 配套或备注。

这些信息继续进入湘源 P1 native semantic evidence 路线。

### 兼容性

- Product/File/Informational version: `0.12.12`
- CLR ABI: `1.0.0.0`
- Host Contract: `SpatialViewer.CadHost >=1.0.0,<2.0.0`
- Release manifest schema: `2`

## English

v0.12.12 adds a strictly gated Xiangyuan land-parcel display fallback based on the v0.12.11 field report. The real `LZX_LAND / AcdbLzxLand` proxy stream translates 115/115 entities with zero unsupported commands, but contains only Color/Marker/FillOn/LwPolyine and no fillable or text primitive.

For an explicitly Xiangyuan `LZX_LAND / AcdbLzxLand` entity on a `YD-*` layer with exactly one closed lightweight proxy polyline, CadCore now draws a display-only background polygon using the resolved CAD layer color, then keeps the original proxy outline above it. Bulged boundaries reuse the existing tessellator only for the fill polygon.

This does not change generic ObjectARX polyline semantics and does not claim or guess parcel-number, land-use, FAR, density, green-rate, height or label semantics.

ABI, Host Contract and manifest schema are unchanged.

## 日本語

v0.12.12 は 0.12.11 の実機レポートに基づき、湘源 `LZX_LAND / AcdbLzxLand` の表示用フォールバックを追加します。実データでは 115/115 entity が正常に Proxy Graphics へ translation され、unsupported は 0 ですが、proxy stream は Color / Marker / FillOn / LwPolyine のみで、fill 可能 primitive や Text を含みません。

明示的な Xiangyuan identity、`LZX_LAND / AcdbLzxLand`、`YD-*` layer、単一の closed lightweight proxy polyline という厳格な条件を満たす場合だけ、解決済み CAD layer color を使った表示専用の背景 polygon を作成し、元の proxy outline はその上に維持します。

generic ObjectARX polyline の意味は変更せず、地块番号、用途、容積率、密度、緑地率、高さ、label などの proprietary semantic は推測しません。

ABI、Host Contract、manifest schema は変更ありません。
