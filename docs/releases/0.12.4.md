# SpatialViewer.CadCore v0.12.4

## 中文

v0.12.4 是针对 v0.12.3 实图验证失败后的 **真实渲染路径修正候选**。本版本不再把普通 `TEXT` / `DIMENSION` 的单元测试等同于天正/自定义对象的真实显示结果，而是直接修正 paper-layout 与 ObjectARX proxy-graphics 路径。

### 修正候选

- **超长直角线 / Fit Extents**：CadCore 过去会把自己合成的 paper-space viewport 矩形放在可见 `__VIEWPORTS__` 图层中。该矩形不是原图实体，却会参与正常渲染和 `Scene2D.GetBounds()`；异常或超大 viewport 因而可能表现为两条极长的直角边并把实际图纸挤到角落。v0.12.4 将该边界降为隐藏的 diagnostic overlay：保留在 `GetItems(false)` 供排查，但不再参与正常显示、命中测试和 Fit Extents。没有采用“超过某长度就隐藏”的启发式规则。
- **图框 proxy 文字**：补齐 ACadSharp `ProxyText2` 与 `ProxyUnicodeText2`。此前这两类 ObjectARX 文字没有进入 CadCore 的 proxy-text 映射，因此普通 TextStyle/SHX 修复可能对实图完全无效。现在保留并传递 font filename、BigFont filename、TrueType typeface、tracking、backward/upside-down/vertical/raw/underline/overline 等显示证据，并在 scene 层按内嵌 typeface 或 CAD 字体解析器选择字体。
- **模型变换与裁剪**：上述 rich proxy text 在 model-transform 与 clip scope 中继续保留字体/布局信息，不因 push/pop transform 或 proxy clip 被降级回普通默认文字。
- **proxy trait provenance**：reader-independent trait 结构新增 subentity layer-index 槽位，为后续定位天正轴网/尺寸对象的 `setLayer()` 颜色继承提供证据；在尚未证明 index→LayerTableRecord 的映射前，不猜测具体图层颜色。

### 回归门禁

- 巨大 synthetic viewport boundary 不得出现在默认 scene items，也不得扩大可见 bounds；diagnostic path 仍可读取该 boundary。
- 正常 model-through-viewport 内容、viewport clip 与 frozen-layer 逻辑继续工作。
- `ProxyText2` 的 SHX/BigFont、tracking 与镜像标志必须进入 reader-independent primitive 和 `TextGeometry`。
- `ProxyUnicodeText2` 的 embedded TrueType typeface 必须优先于无关 UI fallback，并在 model transform 后保持正确位置。

### 仍需实图验收

本版本**不宣称三个原始问题已经全部修复**。第 1、2 项已有命中实际代码路径的候选修正；轴网/`2250` 标注的颜色、位置与缺失斜 tick 仍需通过原问题 DWG 验证其实际 proxy/native 路径。如果 v0.12.4 中该问题仍无变化，下一步将依据 proxy primitive/source trait provenance 继续处理，不回退到普通 DIMSTYLE 猜测。

## English

v0.12.4 is a **real-rendering-path candidate** created after the v0.12.3 real-drawing validation failed. It targets paper-layout and ObjectARX proxy-graphics paths instead of assuming ordinary `TEXT` / `DIMENSION` tests represent Tianzheng/custom-object rendering.

### Candidate fixes

- Synthetic paper-space viewport rectangles are now hidden diagnostic overlays. They remain available through `GetItems(false)` but no longer render, hit-test, or pollute normal Fit Extents.
- Adds `ProxyText2` and `ProxyUnicodeText2` mapping, preserving font filename, BigFont filename, embedded TrueType typeface, tracking, backward/upside-down/vertical/raw/underline/overline evidence.
- Rich proxy text survives model-transform and proxy-clip scopes without being downgraded to generic default text.
- Retains a proxy subentity layer-index provenance slot without inventing an unproven layer-table mapping.

### Real-drawing status

This release does **not** claim all three original defects are fixed. The rogue-line and title-block-text paths now have direct candidate fixes. Axis/`2250` color, placement and missing architectural ticks still require validation on the original failing DWG and will be continued from actual proxy/native provenance if unchanged.

## 日本語

v0.12.4 は v0.12.3 の実図面検証失敗を受けた **実レンダリング経路向け候補修正**です。通常の `TEXT` / `DIMENSION` テストを天正・custom object の表示結果と同一視せず、paper-layout と ObjectARX proxy-graphics 経路を直接修正します。

### 候補修正

- CadCore が合成していた paper-space viewport rectangle を非表示 diagnostic overlay に変更しました。`GetItems(false)` では保持しますが、通常描画・hit test・Fit Extents には参加しません。
- `ProxyText2` / `ProxyUnicodeText2` を追加し、font/BigFont、TrueType typeface、tracking、反転・上下反転・vertical・raw・underline・overline の表示情報を保持します。
- rich proxy text は model transform / clip scope を通過しても既定文字へ劣化しません。
- proxy subentity layer index を provenance として保持する領域を追加しました。index と LayerTableRecord の対応が確認できるまでは色を推測しません。

### 実図面ステータス

本版は元の 3 問題すべての解決を宣言しません。長大な直角線と図枠文字には実際のコード経路を対象とした候補修正があります。軸網/`2250` の色・位置・建築 tick 欠落は元 DWG での再検証後、実際の proxy/native provenance に基づいて継続します。
