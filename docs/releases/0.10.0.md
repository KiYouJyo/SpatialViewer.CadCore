# SpatialViewer.CadCore v0.10.0

## 中文

v0.10.0 是继 v0.9.0 独立更新契约之后的二维 CAD 精度里程碑。本版本集中补齐复杂工程图最容易暴露差异的文字、填充与标注链路，同时继续保持 CadCore 与 SpatialViewer 产品版本解耦。

### 文字与 SHX

- MTEXT 解析层现在识别并保留常用 AutoCAD 控制序列，包括段落/列分隔、Unicode 与字面转义、堆叠文字/分数，以及字体、颜色、高度、宽度、倾斜、字距和装饰等 span 级格式信息。
- 新增编译 SHX 矢量字体引擎，支持 SHAPES / UNIFONT 结构、字形度量、advance、子字形以及常见直线、位移、缩放、栈、圆弧和 bulge 指令；完整字形可直接生成通用 `PolylineGeometry`，不再必须伪装成系统字体。
- 打开 DWG/DXF 时可实际解析引用的 SHX 文件。搜索顺序为：有效绝对路径、图纸目录、宿主通过 `CadFontImportMetadata.ShxSearchPaths` 显式提供的 support 目录；失效的旧电脑绝对路径还会按文件名在这些目录中重新定位。
- 同一导入过程对字体结果缓存；缺失、损坏或超过 32 MiB 安全上限的 SHX 会产生去重警告并安全回退，不会导致整张 CAD 导入失败。

### Pattern HATCH

- 非实心 HATCH 不再只是保留 pattern 名称。CadCore 会保存源文件中的真实 pattern line family：角度、基点、偏移与 dash lengths。
- PAT line family 在 CAD→Scene 边界展开，并按复合边界 even-odd 规则裁剪，带洞填充不会被错误穿透。
- 正 dash、负 gap 与零长度点元素在进入通用渲染器前展开，避免与实体 linetype 再次叠加。
- 对极端小间距 pattern 设置确定性的生成上限，并通过 metadata 明确标记截断状态。

### DIMSTYLE

- 新增 reader-independent `CadDimensionPresentation`，保留二维看图直接相关的 DIMSTYLE：DIMEXO、DIMEXE、尺寸线延伸、DIMGAP、第一/第二延伸线与尺寸线抑制、箭头块身份、精度/舍入、前后缀、公差、备用单位及单位格式信息。
- 线性/对齐尺寸的 Scene 几何实际应用延伸线 offset / extension 与 suppression，而不是仅保存 metadata。
- 自定义箭头块名称及第一/第二箭头身份会被保留；在完整块几何替换尚未实现时仍使用通用箭头，并明确标记 fallback，而不是宣称已经原样渲染。

### 兼容性

- 产品版本、FileVersion 与 InformationalVersion 更新为 `0.10.0`。
- CLR ABI 继续保持 `1.0.0.0`。
- Host Contract 继续保持 `SpatialViewer.CadHost >= 1.0.0` 且 `< 2.0.0`。
- SpatialViewer 本体版本仍不作为 CadCore 更新资格条件；只要 ABI 与 Host Contract 兼容，较早或较新的宿主仍可使用本内核系列。

### 明确未声明为完整支持的范围

v0.10.0 不宣称已经完成 BIGFONT 码页/Unicode 字形组合、逐 span 的 MTEXT 精确富文本视觉布局、自定义 DIM 箭头块的原始块几何渲染、任意非矩形 viewport 的精确裁剪、3D 透视 viewport，以及 streaming / out-of-core / LOD / GPU batching。这些能力继续作为后续版本的独立任务推进。

## English

v0.10.0 is the 2D CAD fidelity milestone following the independent update contract introduced in v0.9.0. It focuses on text, hatch, and annotation paths where complex production drawings most often expose viewer differences, while keeping CadCore decoupled from SpatialViewer product versions.

### Text and SHX

- The MTEXT parser now recognizes and retains common AutoCAD control sequences, including paragraph/column breaks, Unicode and literal escapes, stacked text/fractions, and span-level font, color, height, width, oblique, tracking, and decoration information.
- Added a compiled SHX vector-font engine for SHAPES / UNIFONT structure, glyph metrics and advance, subshapes, and common vector, displacement, scale, stack, arc, and bulge commands. Complete glyph runs can produce generic `PolylineGeometry` instead of pretending to be system-font text.
- DWG/DXF import can now load referenced SHX files. Resolution order is a valid absolute path, the drawing directory, then host-provided support directories through `CadFontImportMetadata.ShxSearchPaths`; stale absolute paths from another machine are also recovered by basename through those directories.
- Font results are cached per import. Missing, invalid, or larger-than-32-MiB SHX files emit deduplicated warnings and fall back safely without failing the whole CAD import.

### Pattern HATCH

- Non-solid HATCH is no longer pattern-name metadata only. CadCore preserves source pattern line families: angle, base point, offset, and dash lengths.
- PAT line families are expanded at the CAD-to-Scene boundary and clipped against compound boundaries with even-odd containment so holes remain holes.
- Positive dashes, negative gaps, and zero-length point elements are expanded before the generic renderer, preventing accidental double application of entity linetypes.
- Pathological tiny-spacing patterns use deterministic generation limits with explicit truncation metadata.

### DIMSTYLE

- Added reader-independent `CadDimensionPresentation` retaining viewer-relevant DIMSTYLE data: DIMEXO, DIMEXE, dimension-line extension, DIMGAP, first/second extension- and dimension-line suppression, arrow-block identity, precision/rounding, prefix/suffix, tolerances, alternate units, and unit-format identity.
- Linear/aligned dimension Scene geometry now actually applies extension-line offset/extension and suppression rather than retaining them as metadata only.
- Custom arrow block names and first/second arrow identities are preserved. Until block-backed arrow geometry lands, the generic arrow remains in use with explicit fallback metadata instead of claiming native custom-arrow fidelity.

### Compatibility

- Product, file, and informational versions advance to `0.10.0`.
- CLR ABI remains `1.0.0.0`.
- The host contract remains `SpatialViewer.CadHost >= 1.0.0` and `< 2.0.0`.
- SpatialViewer application versions remain outside kernel eligibility. Older or newer hosts can consume this kernel line whenever both ABI and Host Contract are compatible.

### Explicit non-claims

v0.10.0 does not claim complete BIGFONT code-page/Unicode composition, exact per-span MTEXT rich visual layout, native custom DIM arrow-block geometry, exact arbitrary non-rectangular viewport clipping, 3D perspective viewports, or streaming / out-of-core / LOD / GPU batching. These remain separate follow-up milestones.

## 日本語

v0.10.0 は、v0.9.0 で導入した独立更新契約に続く 2D CAD 表示精度のマイルストーンです。複雑な実務図面で差が出やすい文字・ハッチング・寸法注記を重点的に改善しつつ、CadCore と SpatialViewer 本体の製品バージョンは引き続き分離します。

### 文字と SHX

- MTEXT 解析で、段落/列区切り、Unicode・リテラルエスケープ、積み上げ文字/分数、span 単位のフォント・色・高さ・幅・傾斜・字間・装飾など、一般的な AutoCAD 制御情報を認識して保持します。
- SHAPES / UNIFONT 構造、字形メトリクスと advance、サブシェイプ、代表的なベクトル・移動・縮尺・スタック・円弧・bulge 命令を扱うコンパイル済み SHX ベクトルフォントエンジンを追加しました。完全な字形列はシステムフォントに見せかけず、汎用 `PolylineGeometry` として生成できます。
- DWG/DXF 読み込み時に参照 SHX ファイルを実際にロードします。解決順は、有効な絶対パス、図面フォルダー、`CadFontImportMetadata.ShxSearchPaths` でホストが明示した support フォルダーです。別 PC 由来で無効になった絶対パスも、ファイル名を使ってこれらのフォルダーから再解決します。
- 同一インポート内ではフォント結果をキャッシュします。欠落・破損・32 MiB の安全上限を超える SHX は重複しない警告を出して安全にフォールバックし、CAD 全体の読み込みは失敗させません。

### Pattern HATCH

- 非 SOLID HATCH は pattern 名だけの metadata ではなく、元データの angle、base point、offset、dash lengths を持つ pattern line family を保持します。
- PAT line family を CAD→Scene 境界で展開し、複合境界を even-odd 規則でクリップするため、穴部分を誤って横切りません。
- 正の dash、負の gap、長さ 0 の point 要素は汎用 renderer に渡す前に展開し、entity linetype の二重適用を防ぎます。
- 極端に細かい pattern には決定的な生成上限を設け、切り詰め状態を metadata で明示します。

### DIMSTYLE

- reader-independent な `CadDimensionPresentation` を追加し、DIMEXO、DIMEXE、寸法線延長、DIMGAP、第1/第2補助線・寸法線の抑制、矢印ブロック識別、精度/丸め、接頭辞/接尾辞、公差、代替単位、単位形式など 2D ビューアに必要な DIMSTYLE 情報を保持します。
- 線形/平行寸法の Scene geometry は、補助線 offset / extension と suppression を metadata だけでなく実際の形状に反映します。
- カスタム矢印ブロック名と第1/第2矢印の識別は保持します。ブロック形状による完全描画が実装されるまでは汎用矢印を使用し、fallback metadata を明示して完全互換とは扱いません。

### 互換性

- Product / File / Informational version を `0.10.0` に更新します。
- CLR ABI は `1.0.0.0` のままです。
- Host Contract も `SpatialViewer.CadHost >= 1.0.0` かつ `< 2.0.0` のままです。
- SpatialViewer 本体の製品バージョンは引き続きカーネル更新条件に使用しません。ABI と Host Contract が互換であれば、古い/新しいホストの双方からこのカーネル系列を利用できます。

### 完全対応を宣言しない範囲

v0.10.0 は BIGFONT のコードページ/Unicode 合成、span 単位 MTEXT の完全なリッチテキスト視覚レイアウト、DIM カスタム矢印ブロックのネイティブ形状描画、任意の非矩形 viewport の厳密クリップ、3D perspective viewport、streaming / out-of-core / LOD / GPU batching の完全対応を宣言しません。これらは後続マイルストーンとして個別に進めます。
