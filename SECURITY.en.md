# Security Policy

[中文](SECURITY.md) · [日本語](SECURITY.ja.md) · [English](SECURITY.en.md)

Do not disclose exploitable parser vulnerabilities, malicious DWG/DXF crashes, or potential code-execution issues in public issues. Use GitHub private security reporting and include a minimal reproducer, affected revision, and environment details.

Ordinary rendering defects, compatibility bugs, and non-security crashes may be reported publicly.
